# Seven-Fold Indigenous Global Church — Resources & Library

Registry Anchor: LoAI-2024-0414-001

This framework expands the existing Church Library without replacing its current Scripture, Indigenous Wisdom, Holistic Education and Publications areas.

## Library collections
- scripture and study resources
- sermons, teachings and ministry education
- Indigenous wisdom and historical/cultural learning resources with respectful attribution and context
- church history, governance and approved public records
- community and family resources
- holistic-living education resources
- publications and authored materials
- minister/leadership learning resources
- ceremonies, traditions and observance resources where appropriate for public access
- interfaith/comparative learning references where appropriate
- service, outreach and community-support resources
- approved external reference links and reading lists

## Resource record
Catalog items should support title, creator/source, date, collection, description, access class, rights/permissions, source link/path, version, related resources and last verification date where relevant.

## Cultural and spiritual integrity
Clearly distinguish the Church's own beliefs/teachings from historical claims and third-party scholarship. Attribute cultural and Indigenous materials carefully, avoid presenting one community's traditions as universal, and preserve restrictions where material is private, sacred, member-only or otherwise not appropriate for public distribution.

## Information integrity
AI summaries are aids, not source texts. AI and technology can make mistakes or omit context. Readers should consult original texts/sources where accuracy matters.

## Access boundary
The public library contains only material intentionally approved for public viewing. Member, pastoral, confidential, sacred/restricted and owner-private materials require separate access controls and must not be published in the public GitHub repository.

## Existing Church Library
The current Church Library remains part of the system. This resources layer is designed to bulk it up into a structured learning and resource service rather than discard existing work.
